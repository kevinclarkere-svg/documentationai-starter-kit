## Recent Releases

Stay up to date with the latest improvements to ParentSearch. Each release includes new features, bug fixes, and enhancements to help you build and access time capsules securely.

<Update label="2024-11-15" description="v1.3.0" tags={["feature", "improvement"]}>
## New Features

- Added support for uploading multiple photos and videos in a single session to streamline time capsule creation.
- Introduced searchable tags for keepsakes, allowing parents to organize memories by themes like "birthdays" or "holidays".

## Improvements

- Optimized search performance for partial name matches, reducing load times by up to 40%.
- Enhanced mobile responsiveness for the search interface on tablets and phones.

## Bug Fixes

- Fixed issue where video messages failed to upload on slower connections.
- Resolved display errors for time capsules viewed in private browsing mode.
</Update>

<Update label="2024-10-20" description="v1.2.0" tags={["feature", "bugfix"]}>
## New Features

- New privacy dashboard where users can review and manage capsule access logs.
- Added option to schedule future message unlocks based on child age milestones.

## Improvements

- Updated UI with brand color accents (#c0272d) for better visual consistency.
- Improved letter editor with rich text formatting and spell check.

## Bug Fixes

- Corrected search results pagination that skipped pages on large result sets.
- Patched vulnerability in file upload validation for added security.
</Update>

<Update label="2024-09-10" description="v1.1.0" tags={["breaking", "improvement"]}>
## Breaking Changes

- Removed legacy email notifications; now uses in-app alerts only for better privacy.

## New Features

- Integrated first-name and partial last-name search with optional city filters.
- Added time capsule preview mode before finalizing submissions.

## Bug Fixes

- Fixed login issues for users with special characters in names.
- Resolved capsule sharing errors between parent and child portals.
</Update>

<Callout kind="info">
Check the [Parent Portal](https://parentsearch.org/login) after updating to experience the latest features. Backup your time capsules regularly.
</Callout>
